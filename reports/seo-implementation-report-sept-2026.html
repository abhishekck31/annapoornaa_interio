3Page Speed — Image Compression

Five images were doing more damage to load time than the rest of the site combined.

A reusable script (scripts/optimize-images.mjs, using the sharp library) was written to resize each file to a maximum width of 1600 px and re-encode it as WebP at quality 80. It is safe to re-run and skips anything already processed.

4Modern Image Delivery (Layout-Shift Fix)

Old-style image tags don’t reserve space while loading, which causes content to jump — a ranking factor Google measures as CLS.

Twenty-one raw <img> tags were converted to the framework’s image component, which serves modern formats, sizes images to the device, and lazy-loads anything below the fold. Every converted image was given either explicit width and height or a fixed aspect-ratio container, so no space is left undefined.

FileTags convertedMethod
app/expertise/construction/page.tsx5Fixed 300×300 grid; 3:2 container for cards
app/expertise/interior/page.tsx5Fixed 300×300 grid; 3:2 container for cards
app/featured-projects/page.tsx4Fill within fixed-height / aspect parents
app/about/page.tsx1Explicit 448×400 (CEO portrait)
6 × location page project carousels6Fill within the existing h-72 card
  • Placeholder-image fallbacks were pointed at a real raster file instead of an SVG, so the optimiser never has to be bypassed.
  • components/partners-section.tsx was deleted — it was never imported by any page (dead code carrying its own unoptimised image).
  • Two <img> tags remain by design: a 16 px Google “verified review” icon, and one homepage project thumbnail that depends on natural aspect ratio and is already lazy-loaded.

5Image Alt Text

Product images described themselves in one or two words. Search engines and screen readers got nothing useful.

Thirteen alt descriptions across the seven product pages were rewritten from bare labels (“Fire Doors”, “System Railings”) to specific, location-aware sentences, e.g. “Fire-rated steel and timber doors for commercial and residential buildings in Bangalore — ACIPL”. Collection-grid images now build their alt text from the product name plus a service-and-city suffix, so every thumbnail is described.
