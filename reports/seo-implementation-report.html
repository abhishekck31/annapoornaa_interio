1Executive Summary

What was wrong, what we did about it, and what it means commercially.

A full audit of the website uncovered several faults that were actively preventing Google from indexing and ranking the site correctly — including thirteen location pages that were invisible to search engines, a sitemap file that Google could not read at all, and a social sharing image that had been broken sitewide. All of these have been corrected.

Beyond the repairs, we built sixteen new landing pages targeting commercially valuable searches such as “modular kitchen in Whitefield” and “home renovation in JP Nagar”. Each is written specifically for that service and locality rather than being a copy with the area name swapped, which is what search engines penalise.

2Critical Faults Found & Fixed

Each of these was measurably harming search visibility before this work began.

IssueBeforeAfter
13 location pages invisible Pages for Koramangala, Hebbal, HSR Layout and ten other areas were built with a method incompatible with the site’s framework. They published no page title and no description — Google saw thirteen identical, empty pages. Consolidated into properly built pages and permanently redirected, so their accumulated value transfers rather than being lost.
Sitemap unreadable The sitemap file was corrupted — a structural tag was never closed, making it invalid. Google could not parse it, so it could not reliably discover pages. Rebuilt and generated automatically. Now lists all 41 pages correctly and updates itself whenever a page is added.
Social image missing Every page referenced a preview image that did not exist. Any link shared on WhatsApp, Facebook or LinkedIn appeared blank and untrustworthy. Created and live. Shared links now display a proper branded preview.
Split website address Roughly half the site pointed to ac-ipl.in and half to www.ac-ipl.in. Google treated these as two competing sites, dividing ranking strength between them. Unified on www.ac-ipl.in throughout, consolidating all authority into one address.
Conflicting business details The site declared three different versions of the business to Google — with different email addresses, phone formats and social media links. A single, consistent business profile. Essential for Google Maps and local search reliability.
Slow-loading homepage Homepage banner images were 6.4 MB each and loaded in a way the browser could not prioritise — punishing on mobile data. Reduced to 343 KB with no visible quality loss, and now loaded first.
Placeholder code left live The homepage published a dummy Google verification tag reading your-google-verification-code. Removed.

3Work Completed by Area

Technical foundations

  • Sitemap and robots file rebuilt and now generated automatically from a central list.
  • Removed a sitemap entry pointing to a page that did not exist (returning an error to Google).
  • Every page given a single correct canonical address, eliminating duplicate-content risk.
  • Search engines blocked from crawling internal system routes with no public value.
  • Proper “page not found” page added, so error pages no longer confuse indexing.

On-page optimisation

  • Unique, keyword-focused page title and description written for every page — including nine product and service pages that previously had none at all.
  • Page titles shortened where they were being cut off in Google results.
  • Main headings added to the Services and Gallery pages, which were missing them.
  • Homepage heading fixed: it previously rotated between three generic phrases every five seconds, so search engines never saw a consistent, meaningful heading.
  • Descriptive image alternative text improved for accessibility and image search.

Google rich results (structured data)

  • One authoritative business profile covering name, address, phone, hours and service areas.
  • Service information added to every service and landing page.
  • Frequently Asked Questions marked up so answers can appear directly in Google results.
  • Navigation breadcrumbs added, which Google displays beneath listings.

Speed & mobile experience

  • Homepage banner images reduced by 95% and converted to a modern format.
  • Duplicate font loading removed — the site was downloading the same font twice.
  • Gallery corrected: eight images were competing for priority and slowing the visible content.
  • Image delivery tuned so phones receive appropriately sized images instead of desktop versions.
  • Removed a script that forced the page to jump to the top, which was breaking menu links.

6What to Expect, and When

An honest timeline. SEO results are not immediate, and anyone promising otherwise should be treated with caution.

TimeframeExpected development
Week 1–2 Google reads the new sitemap and begins crawling the new pages. Faster loading takes effect immediately for visitors.
Week 2–4 New landing pages enter the index and start appearing for long-tail searches. Impressions in Search Console begin rising.
Week 4–8 Redirected pages consolidate, unifying ranking strength onto single addresses. FAQ answers and breadcrumbs may begin appearing in results.
Month 2–4 Location pages compete meaningfully for “service + area” searches. This is where qualified enquiries typically start to show.
Please note: this report documents work implemented, not results achieved. Rankings depend on competition, backlinks, Google Business Profile activity and review volume — factors outside the website itself. The technical foundation is now correct, which is a prerequisite for ranking, not a guarantee of it.

7Recommended Next Steps

Requires a decision from you

  • Customer review rating. The website currently tells Google it holds a 4.9 rating from 47 reviews, but no reviews are displayed on the site to support this. Google can issue a penalty for unverifiable claims of this kind. We recommend either displaying genuine reviews or removing the claim. Priority
  • Third-party watermark. One photograph on the site carries another design studio’s watermark and should be replaced.
  • Unused image files. Around 40 MB of images are stored but not used anywhere. Safe to remove once confirmed.

Ongoing activity we recommend

  • Keep the Google Business Profile active with fresh project photographs and posts — the strongest single factor for local map rankings.
  • Request reviews from completed clients, ideally mentioning the specific area and service.
  • Publish project case studies to the blog, linking to the relevant location pages.
  • Expand into further areas using the new page system as demand indicates.
  • Review Search Console monthly for coverage issues and emerging search terms.
